## 5. 新版 E6 四项核心实现说明

对应 [小组新版报告](REPORT.md) 的四项代码阅读任务；实现位于 [autobuild.py](../../services/draft/draft/autobuild.py)，CLI 位于 [cli.py](../../services/draft/draft/cli.py)。以下说明对应本人实际运行源码 `c220521c078a2b32f28fa70def896197f986c8a7`，不是新增四项算法实现。

### 1. 固定 FROM 与必需指令

`instructions` 折叠 Dockerfile 续行并去除注释；`prepare_candidate` 要求单阶段、带 sha256 摘要的 FROM，初始镜像只能使用同一标签对应的固定摘要，已有摘要不能替换。函数按顺序匹配原 WORKDIR、COPY、RUN make、CMD，只允许额外加入 RUN 修复依赖。本人的两个输出目录边界用例与外部符号链接用例验证 `auto_build` 在复制输入和 Docker 构建前拒绝不安全输入，不改变候选约束。

### 2. 首轮失败分类与停止条件

`classify_failure` 将 shell 的 make 不存在归为 MISSING_MAKE，源解析、网络请求等错误归为 INFRASTRUCTURE，其他构建错误归为 OTHER_BUILD_ERROR。`auto_build` 只在第一轮非零且分类 MISSING_MAKE 时进入第二轮；首轮成功或其他错误立即停止，第二轮构建非零也不会继续程序验证。本人 [result.json](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/result.json) 记录第一轮退出 1、MISSING_MAKE；[完整首轮 stderr](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/iter-01/build-stderr.log) 包含 make: not found。

### 3. 构建镜像与运行镜像一致

第二轮构建后调用 docker image inspect 获取 Id，写入 attempts[1].image_id，并将该 ID 直接作为 docker run 的镜像参数，避免标签被改写导致验证其他镜像。本人第二轮 ID 为 `sha256:b01af984861ae990f982d4205fe2b3b18fc927f5b7c8e33bc305fd124dd17439`；[image-inspect.json](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/iter-02/image-inspect.json)、result.json 的 attempts 与 verification.command 三处一致。运行参数包含 --network none。

### 4. 退出码和输出联合检查

实现保存退出码、actual_output、expected_output，并仅去除输出末尾换行后比较。只有退出码为 0 且 output_matches=true 才得到 SUCCEEDED；退出 0 但输出不符仍失败。本人第二轮 build_exit_code=0，最终 exit_code=0、actual_output 为 hello E3 加换行、output_matches=true；原始 [verify.log](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/verify.log) 与 result.json 对应。完整门禁中的 [wrong-output 结果](../../artifacts/e5-e7/241250017-20261101/final-gate/gate/wrong-output/evidence/result.json) 为 FAILED，说明不能只凭镜像构建成功判定修复成功。

两轮实际 Dockerfile：[第一轮](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/iter-01/Dockerfile)、[第二轮](../../artifacts/e5-e7/241250017-20261101/final-e6/evidence/iter-02/Dockerfile)。修复保留 FROM、WORKDIR、COPY、RUN make、CMD，增加 Debian 镜像源配置及 build-essential 安装，提供 make 与 C 编译工具。候选选择依据和实际输入哈希分别见个人来源表及 result.json/input_sha256。
