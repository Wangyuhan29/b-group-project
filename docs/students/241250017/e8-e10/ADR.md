# ADR-241250017：容器复跑与补丁隔离验证

日期：2026-11-14。状态：已采用。

## 1. 背景

固定基线提供 E8/E9 B 轨道教学实现；其参考运行使用宿主工具。个人要求优先课程容器，且不能修改原项目或他人材料。

## 2. 决策

复用本人已有课程 DRAFT 容器的固定内容，补装 GCC/make，保存 Dockerfile 和实际镜像 ID。宿主机只负责 Git 同步及 Docker 调度，功能测试在禁网课程扩展容器执行。

保留 lab.py 原实现，个人验证器调用 demo 生成固定报告、补丁、计划；对三个风格保存输入与前后指纹，并在各自独立副本实际应用。macro 副本额外构建与运行；不在原输入目录执行 git apply。

新增两项测试分别覆盖不存在的依赖文件拒绝，以及 macro 定义修复不破坏目标引用或配方，避免重复参考测试。

## 3. 备选方案与取舍

直接使用宿主 GCC 更省安装时间，但不满足本次优先容器的目标。复用他人镜像标签容易覆盖他人成果，因此使用本人标签。仅检查补丁字符串或 --check 不足以证明可实际应用，故增加独立副本应用与重新 scan。

## 4. 结果与限制

11 项测试和 E8/E9 验证均通过；三份原项目指纹保持不变。传统构建器解决本地镜像摘要被 BuildKit 强行联网解析的问题；镜像工具具体版本在证据中记录。该结果不扩展为任意复杂 Makefile 或 E10 事务验证完成。
