# ADR-001 异步任务模型

状态：Proposed，待 A/B 签字确认。

## Context
构建与检测可能超过 HTTP 生命周期。PPT 6–9、19、27 要求统一任务单、异步受理和查询。

## Decision
四种任务共享公共字段。POST 202 返回服务端 job_id，GET 查询完整状态。创建请求和查询记录分开建模。六种状态沿用课程命名；检测发现放报告，系统错误放 job.error。MD 本身不导致 FAILED。

## Alternatives
同步等待：实现简单，但长任务容易超时。每个工具独立状态格式：局部灵活，但下游难统一处理。

## Consequences
后续需要任务存储、幂等处理与执行器。当前只交付契约，状态迁移与幂等执行尚未实现。由 Schema、四组请求/响应和状态样例验证设计。
